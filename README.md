# הפרשת תרומות ומעשרות 🌾

אפליקציית web (PWA) שעוזרת להפריש תרומות ומעשרות: בוחרים נוסח, סוג גידול ותאריך,
והאפליקציה בונה את **הנוסח המדויק** ואת **ההנחיות שלב-אחר-שלב** — בהתאם לשנת המעשר,
לסוג הפרי, לנטע רבעי, לשמיטה, ולמצב ודאי/דמאי.

> ⚠️ **הבהרה:** כלי עזר ללימוד בלבד, אינו פוסק הלכה. יש לוודא הלכה למעשה מול רב מוסמך.

## יכולות

- **בחירת נוסח:** מקובל (סידורים), עדות המזרח, חזון איש, תימני (בלדי/רמב"ם), ומקוצר.
- **חישוב שנת מעשר אוטומטי** מתאריך הלקיטה, עם התחשבות בגבול השנה לפי סוג הגידול
  (ט״ו בשבט לפירות אילן, ראש השנה לירקות/תבואה/קטניות) — או בחירה ידנית.
- **זיהוי מעשר שני / מעשר עני / שמיטה** לפי מחזור השמיטה (עוגן: תשפ״ב).
- **נטע רבעי / ערלה:** הערכה לפי שנת נטיעה (כולל כלל ט״ו באב), או קביעה ידנית.
- **דמאי מול ודאי טבל:** קובע אם מברכים ומתאים את הנוסח.
- **הנחיות מעשיות:** ייחוד מטבע לחילול, סדר הברכות, וטיפול בתרומה.
- **PWA:** ניתנת להתקנה במובייל ולעבודה אופליין.

## הרצה

```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה לפרודקשן (dist/)
npm run preview  # תצוגה מקדימה של הבנייה
```

## ארכיטקטורה

```
src/
  domain/      לוגיקת הליבה (ללא UI)
    types.ts        טיפוסים
    hebrewDate.ts   המרת תאריך עברי (@hebcal/core)
    maaserYear.ts   מחזור השמיטה + קביעת שנה לפי סוג גידול
    produce.ts      קטלוג גידולים
    orlah.ts        הערכת ערלה/נטע רבעי
    engine.ts       הרכבת תרחיש מלא
  nusach/
    nusachim.ts     נתוני הנוסחים (מפורקים לסעיפים)
    generate.ts     מנוע בניית ההנחיות והנוסח
  components/  רכיבי UI
  App.tsx      תזמור והאשף
```

המנוע (`domain` + `nusach`) מנותק מה-UI, כך שקל לבדוק אותו ולהרחיב נוסחים נוספים
על-ידי עריכת `src/nusach/nusachim.ts`.

## מקורות

ראו קישורי המקור בתחתית האפליקציה. הטקסטים של "מקובל" ו"עדות המזרח" צוטטו
מוויקיטקסט; "חזון איש" עובד ממקור מקוון; "תימני" מבוסס נוסח הרמב"ם/מהרי"ץ;
"מקוצר" מבוסס הנוסח הקצר המקובל.
